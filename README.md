# This is _**halloShell**_

A minimal shell implemented in Rust.

Right now this minimal shell has:

---

## Built-in commands

```
cd
echo
pwd
type
exit
```

## Features

- Navigation using **cd** and **pwd**
- Quoting support for **echo**
- Error and output redirection of **stdout** and **stderr**:
  - `>` and `1>` — redirect stdout (truncate)
  - `2>` — redirect stderr (truncate)
  - `>>` and `1>>` — append stdout
  - `2>>` — append stderr
